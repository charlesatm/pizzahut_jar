# Share a Slice

Share a Slice is a community collection of Pizza Hut Sri Lanka Loyalty and GES voucher codes.

## Loyalty verification

New and edited Loyalty codes are verified server-side against Pizza Hut before they are saved.
The deployment requires these server-only environment variables:

- `PIZZA_HUT_API_USERNAME`
- `PIZZA_HUT_API_PASSWORD`
- `PIZZA_HUT_API_SCOPE`

`PIZZA_HUT_API_BASE_URL` is optional and defaults to `https://phapis.pizzahut.lk`.
